# 플레오더 0.2.2

차량 Gleo에 치킨을 주문하면 플레오더가 견적을 엽니다. 총액과 카드를 듣고 말로 승인한 뒤, 차량 설정에서도 같은 주문의 현황을 물을 수 있습니다. 결제와 매장 접수는 공모전용 시뮬레이션입니다.

- **차량 음성 연결**. 기본 음성 비서에서 플레오더로 이어지는 App Schema 동작 8개를 제공합니다. 차량 설정 → 견적, 명시적 모의 승인, 백그라운드 현황 조회를 공식 API 34 에뮬레이터와 한국어 합성 입력으로 시험했습니다.
- **음성 배송지**. 장소 후보를 번호로 고르고, 동·호수는 인식한 숫자를 다시 들은 뒤 확인하면 저장됩니다. 잘못 들은 숫자는 저장 전에 정정할 수 있습니다.
- **예약 배달과 픽업**. 대표 영상 0:59에서 교통 정체로 차량 도착이 15분 늦어지는 상황을, 1:16에서 픽업 경유 확인과 음식 수령을 볼 수 있습니다.
- **주행과 결제**. 주행 화면의 음성 버튼으로 시스템 Gleo를 열 수 있습니다. 견적 확인 유효 시간과 주차 화면 복귀 시 주문 상태 공유를 수정했습니다. 야간 대비와 가로 화면 비율을 점검했고 회귀 검사 144개가 통과했습니다.

내레이션과 운전자는 서로 다른 한국어 ElevenLabs 음성입니다. 차량 답변은 실제 Gleo 스피커 출력을 녹음했습니다. 세 영상은 1080p 30fps이며 결제·배달은 시뮬레이션입니다.
