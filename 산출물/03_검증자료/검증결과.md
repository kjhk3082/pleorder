# 출품본 검증 결과

확인일: 2026-11-12. 주문·결제는 시뮬레이션입니다. 성공한 실행과 미완료 검증을 구분합니다.

## r2 추가 수정과 재검증

- 주소 모달 안에 마이크 준비·듣기·인식 결과·오류를 표시합니다. 숫자로 읽은 동호수를 정리하고, 백그라운드 상태 갱신이 편집 중인 상세주소를 덮어쓰지 않도록 수정했습니다.
- 주문·결제 및 대화 선택 창 안에 ‘말로 답하기’ 버튼을 추가했습니다. 버튼 클릭만으로 결제하지 않으며, 최종 음성 명령의 명시적 승인이 필요합니다.
- STT 초기화·인식 제한시간, 이전 세션의 오디오 포커스 콜백, 종료 후 오류 콜백, 리스너·엔진 정리를 보완했습니다.
- r2 release 빌드·서명·비밀키 비포함 확인, 실제 API 34 설치·주차 화면·주소 입력의 ‘듣고 있어요’ UI까지 확인했습니다. 전체 음성 입력 완료 및 주문까지의 연결은 확인하지 못했습니다.
- Android Emulator 37.2.13과 별도 공식 36.4.9에서 host / 소프트웨어 렌더러 및 일반·headless 실행을 비교했습니다. 덤프에서 `0xc0000005`와 그래픽 모듈(`libGLESv2.dll`, `libgfxstream_backend.dll`) 충돌을 확인했고, 다른 실행에서는 QEMU 모듈 충돌·ADB/gRPC 단절이 발생했습니다. 모든 실패를 하나의 원인으로 단정하지 않습니다.
- 마이크 선연결 시험 1회는 `AUDIO_INJECTED`로 전송을 마쳤지만 직후 ADB 연결이 끊겼습니다. 오디오 전송 성공을 음성 인식·주문 성공으로 집계하지 않습니다. release 주소→상세주소→주문→승인→조회 **완료된 반복 회차는 0회**입니다.
- 배포 영상은 기존 7분 16초 촬영본입니다. README에는 GitHub 첨부 플레이어를 연결하고 서버 렌더링의 `<video controls>`를 확인했습니다. r2 음성 성공 영상으로 대체하지 않았습니다.

## 환경

- Pleos `release_connect_v2.1.0`, Android API 34, x86_64, 물리 화면 2560×1440, density 160.
- Android Emulator 37.2.13.0 및 추가 비교 36.4.9. 실제 시험은 별도 read-only 인스턴스에서 진행했습니다.
- 공개 SpeechToText / TextToSpeech 3.3.1 ON_DEVICE, FusedLocation 1.1.3, NaviHelper 3.0.5.
- 지도는 Naver입니다. 영상의 개발 빌드는 로컬 프록시의 Directions 5를 사용할 수 있습니다. 독립 실행 release는 해당 프록시를 내장하지 않고 대체 도로 경로를 사용합니다.
- release는 개발 테스트 서명이며 상용 배포 서명이 아닙니다. APK 크기로 인해 GitHub Releases에 제공합니다.

## 음성 결과의 정확한 의미

음성 장면에서 앱 함수를 직접 호출해 성공 상태를 만들지 않았습니다. Windows 한국어 합성 음성을 에뮬레이터 가상 마이크에 넣고 공개 SDK의 최종 인식 결과가 주문 엔진으로 들어가는 경로를 사용했습니다. 부분 인식은 실행하지 않으며 중복 최종 결과를 한 번만 처리합니다. 이전 세션 콜백은 세대 번호로 무시하고 종료 시 STT 리스너를 제거합니다.

인식 문장 일부가 ‘비빔밥 한 기업에 배달해 줘’처럼 부정확한 경우도 있었습니다. 최종 상품과 수량, 총액을 다시 확인한 후 별도의 ‘결제 승인’으로 진행합니다. ‘비빔밥 한 개’를 정확히 한 글자도 틀리지 않고 인식했다고 주장하지 않습니다. 음성은 규칙 기반 앱 명령 엔진으로 해석하며, 출품판에서 Gleo LLM이나 추출된 모델을 실행하지 않습니다.

## 미완료·실패 및 한계

- 반복 촬영 중 에뮬레이터 프로세스 종료 또는 ADB/gRPC 연결 정지가 재현됐습니다. 일부 실행에는 그래픽 ColorBuffer 오류가 있었지만 모든 종료의 원인이 확정된 것은 아닙니다. 다른 사용자의 재시작 때문이라고 단정하지 않습니다.
- 공개 음성 SDK의 주문·승인·조회 성공은 debug에서 확보했습니다. 최종 release에서도 추가 마이크 입력을 시도했으나 에뮬레이터 연결 문제가 발생해 같은 과업의 완료를 확인하지 못했습니다. release 음성 반복 안정성은 미완료입니다.
- 목적지·상세주소 음성 UI는 공개 STT에 연결했지만, 이번 추가 에뮬레이터 시험에서 입력 완료를 안정적으로 재현하지 못했습니다. 기존 단위 검사 및 과거 Gleo 연구 성공을 현재 공개 STT 실기 성공으로 대체하지 않습니다. 영상의 주소 장면은 텍스트 검색입니다.
- 새 영상의 픽업은 내비 전송 확인창까지입니다. 과거 NaviHelper 콜백 성공은 기존 연구 기록을 참고하며, 이번 영상의 실제 경로 반영 성공 증거로 제시하지 않습니다.
- 실차·사람 목소리·잡음 환경·상용 서버 부하·실결제·실제 배달권역·실제 매장 주문 접수는 검증하지 않았습니다. 모든 예외 상황을 영상에 촬영하지 않았습니다.
- Gleo Interface 승인은 별도이며 현 공모전 참가팀의 신청은 공식 공지상 불가능합니다. 이전 실험을 승인·무료 사용·완전 오프라인 실행의 근거로 사용하지 않습니다.

## 제출 전 재현 권장 순서

1. 공식 에뮬레이터에서 음성 모델 준비 상태와 마이크 권한을 확인합니다.
2. `apk/README.md`의 release를 설치하고 P단 탐색 → D단 화면 전환을 확인합니다.
3. 마이크 주문 → 총액·상품 확인 → 명시적 승인 → 현황 조회를 반복하고 실패율을 기록합니다.
4. 목적지와 상세주소 음성 입력은 재검증이 끝날 때까지 텍스트·지도 선택 경로를 함께 안내합니다.
5. 신한카드 한도 부족 → 현대카드 재승인, 예약 보류·재개, 완료 사진, 설정과 초기화를 확인합니다.
