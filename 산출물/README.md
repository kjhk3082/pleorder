공식 접수양식과 이메일 초안은 이 컴퓨터의 `비공개_접수용` 폴더에만 있습니다. 대표자와 팀원 이름이 들어 있어 GitHub에 올리지 않습니다. 연락처·역할·개별 동의·서명·날짜를 당사자가 작성한 뒤 제출해야 합니다. 이메일 접수는 아직 수행하지 않았습니다.

영상에는 실제 에뮬레이터 화면과 합성 설명 음성을 사용했습니다. 음성 SDK 장면은 합성 시험 입력과 실제 TTS 응답입니다. 시간 가속과 시험 이벤트를 표시했습니다. 시스템 Gleo 실기 영상은 release 0.2.2에서 녹화했습니다. 매장 접수와 결제는 시뮬레이션입니다.

내부 분석 아카이브, 모델·프롬프트, 인증정보, 주거 상세주소, 원시 로그는 공개 산출물에 포함하지 않습니다.
